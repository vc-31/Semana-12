# 🎬 Sistema de Reserva de Asientos de Cine

*Estudiante: Lilibeth Valeria Castro Serrano*

## 🎯 ¿Cuál es su objetivo?
Este programa sirve para *organizar y controlar los asientos de una sala de cine. Su propósito es evitar que dos personas reserven el mismo lugar y permitir que veamos de forma sencilla qué puestos están libres y cuáles ya están ocupados. Está diseñado para una sala pequeña de **3 filas y 4 asientos en cada fila*.

## ⚙️ ¿Cómo funciona?
El programa representa la sala como una tabla donde cada asiento tiene un número:
- *0* → El asiento está *libre*, puedes sentarte ahí.
- *1* → El asiento está *ocupado*, alguien ya lo reservó.

Cuando lo inicias, aparece un *menú con tres opciones*:
1. *Reservar un asiento:* El programa te pregunta qué fila y qué número deseas. Revisa que los datos sean correctos, verifica si está libre, y si todo está bien, lo marca como ocupado y te confirma la reserva.
2. *Ver la sala:* Muestra en pantalla toda la sala organizada, para que veas de un vistazo qué lugares están disponibles.
3. *Salir:* Cierra el programa cuando termines.

El programa se mantiene funcionando *hasta que tú decidas salir* escribiendo el número 0.
